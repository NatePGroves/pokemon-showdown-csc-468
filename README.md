# Instructions for running showdown
1. For running a server, you have to start the the server first. In a terminal window go into the poke-env (cd poke-env)
2. Then run:    cp config/config-example.js config/config.js
                node pokemon-showdown start --no-security
3. Finally, you can run example_script.py or train_eval and it should run all the battles. To see the battles you can open http://localhost:8000 and watch replays.
4. Close the server or end running early by entering Cntrl+C (might be CMD+C for mac) in the command window.
